# Portfólio — Hélio Goullart

Site estático em HTML, CSS e JavaScript, pronto para publicação com GitHub Pages.

## Publicar
1. Crie um repositório no GitHub, por exemplo `portfolio`.
2. Envie `index.html`, `.nojekyll` e `README.md` para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)` e clique em **Save**.
6. Aguarde a publicação; o GitHub exibirá a URL do site na seção Pages.

Antes de publicar, substitua o e-mail de exemplo e os links sociais genéricos no `index.html`, além das capas demonstrativas pelas imagens reais dos projetos.
